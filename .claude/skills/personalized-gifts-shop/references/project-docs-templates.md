## docs/owner-guide.md (נכתב בשלב 6)
מדריך בעברית פשוטה לבעלת העסק, עם צילומי מסך:
- איך מוסיפים מוצר חדש ומגדירים לו שדות התאמה
- איך משנים מחיר או מסמנים "לא זמין"
- איך מטפלים בהזמנה חדשה: צפייה, הורדת קבצים, שינוי סטטוס
- מה עושים כשהזמנה מסומנת "נדרש בירור"
- למי פונים כשמשהו לא עובד
