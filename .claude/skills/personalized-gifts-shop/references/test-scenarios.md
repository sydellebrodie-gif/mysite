# תרחישי בדיקה

כל תרחיש רץ **מקצה לקצה**: מדף המוצר, דרך תשלום (במצב בדיקה), ועד בדיקה במסך הניהול, בדף הייצור ובהודעת האישור.
מריצים בטלפון (רוחב 390px, וגם במכשיר אמיתי אם אפשר) ובמחשב. משתמשים בנתונים מומצאים בלבד.
אם יש Playwright, מומלץ להפוך את תרחישים 1–4 לבדיקות אוטומטיות.

## תרחישים עיקריים

### 1. מוצר רגיל
מוצר בלי התאמה ← וריאציה ← כמות 2 ← סל ← משלוח ← תשלום.
✔ המחיר נכון (מוצר × 2 + משלוח). ✔ ההזמנה בסטטוס "חדשה". ✔ במייל האישור מופיע הפריט.

### 2. מוצר עם תמונה וטקסט
כוס ← העלאת תמונה מהגלריה בטלפון (גם HEIC) ← תצוגה מקדימה ← **החלפת התמונה** ← שם + הקדשה ← סל ← עריכה מהסל (שינוי ההקדשה) ← תשלום.
✔ התמונה שבהזמנה היא **התמונה המוחלפת**, לא הראשונה. ✔ ההקדשה מעודכנת. ✔ הקובץ המקורי יורד מהניהול בגודל המלא. ✔ במייל האישור מופיעים הטקסטים.

### 3. אותו מוצר עם התאמות שונות
כוס עם תמונה A ושם "דנה" ← הוספה לסל ← "עוד אחת עם עיצוב אחר" ← תמונה B ושם "יוסי".
✔ בסל ובהזמנה יש שתי שורות נפרדות. ✔ כל תמונה מקושרת לשם הנכון. ✔ שמות הקבצים להורדה מבדילים בין הפריטים.

### 4. מארז עם כמה מוצרים מותאמים
מארז בהרכבה ← כוס (תמונה C + שם) + מגבת (טקסט) + מדבקה (תמונה D) ← בחירת אריזה ← המחיר מתעדכן אחרי כל צעד ← סל ← עריכת המגבת מתוך המארז ← תשלום.
✔ בניהול המארז מוצג כקבוצה, ולכל פריט ההתאמה שלו. ✔ C שייכת לכוס ו־D למדבקה. ✔ המחיר = סכום הפריטים + אריזה ± כלל ההנחה. ✔ אי אפשר לעבור את המקסימום או לשלם מתחת למינימום. ✔ מוצר שאינו מותר במארז לא מוצג בבונה.

## תרחישי ולידציה
- שדה חובה ריק ← לא ניתן להוסיף לסל, וההודעה מופיעה ליד השדה.
- טקסט ארוך מהמגבלה ← יש מונה תווים, והקלט נעצר במגבלה או שמוצגת שגיאה.
- קובץ PDF או קובץ גדול מהתקרה ← הודעה ברורה בעברית.
- תמונה ברזולוציה נמוכה (למשל 400×300 לכוס) ← מוצגת אזהרת איכות, ואפשר להמשיך.

## תרחישי כשל
### 5. כשל בהעלאה
לנתק את הרשת באמצע ההעלאה.
✔ הודעה ברורה + "נסו שוב". ✔ שאר השדות נשארים מלאים.

### 6. כשל בתשלום
כרטיס בדיקה שנדחה.
✔ חזרה לקופה כשהסל וההתאמות שמורים. ✔ לא נוצרה הזמנה ששולמה.

### 7. רענון וסגירת דפדפן
סל עם פריט מותאם ומארז ← רענון ← סגירה ופתיחה מחדש.
✔ הסל, ההתאמות והתמונות נשמרו.

### 8. אישור תשלום כפול או מאוחר
לשלוח את ה־webhook פעמיים, או לסגור את הדפדפן לפני ההפניה חזרה מהסליקה.
✔ נוצרה הזמנה אחת בלבד. ✔ ההזמנה נוצרה גם בלי ההפניה.

## תרחישי פרטיות
- להעתיק כתובת של תמונת לקוח מהניהול ולפתוח אותה בחלון גלישה בסתר ← הגישה נחסמת או שהקישור פג.
- לנסות להיכנס לכתובת הניהול בלי התחברות ← הגישה נחסמת.
- לחפש במאגר הקוד מפתחות (`git grep -iE "secret|api[_-]?key|token|password"`) ← לא נמצא שום ערך אמיתי.
