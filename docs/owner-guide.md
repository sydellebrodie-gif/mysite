# מדריך קצר לניהול האתר
**כתובת:** `<כתובת האתר>/admin` · **עודכן:** 2026-11-20 · יורחב לפני ההשקה

## כניסה
מייל, סיסמה, ואז הקוד מאפליקציית האימות בטלפון. בפעם הראשונה סורקים קוד כדי לחבר את האפליקציה.

## הזמנה חדשה
1. **הזמנות** ← הלשונית "פתוחות". הזמנה שסומנה "נדרש בירור" מודגשת בצהוב.
2. נכנסים להזמנה. כל חלק בעמוד נשמר לבד, בכפתור השמירה שלו.
3. **דף ייצור להדפסה:** כל הטקסטים, הבחירות ושמות הקבצים של כל פריט.
4. **קבצים:** "הורדת כל הקבצים". תמונות מאייפון יורדות כ־JPG (אפשר לבטל את הסימון ולהוריד את המקור).
   שם כל קובץ מזהה את הפריט, למשל `1001-2-ספל-לבן.jpg`, ובמארז `1001-מארז1-3-מחזיק-מפתחות.jpg`.
5. מעדכנים סטטוס: בהכנה ← מוכנה ← נשלחה / נאספה.
6. אחרי שכל הקבצים במחשב: "מחיקת הקבצים מהענן" (מסמנים שהקבצים נשמרו). אחרי זה הדפסה חוזרת אפשרית רק מהקובץ שבמחשב.

## לקוח שלח תמונה בוואטסאפ או במייל
בהזמנה, ליד הפריט: "+ העלאת קובץ לפריט". הסימון "ממתין לתמונה" יורד לבד.

## תיקון פרטים בהזמנה
פרטי לקוח, כתובת, דרך מסירה, טקסט על מוצר: עורכים בחלק המתאים ושומרים. הסכום ששולם לא משתנה. החזר כספי נעשה במערכת הסליקה.

## מוצרים
- **מחיר, מבצע, מלאי, תמונות:** בעמוד המוצר, כל אחד בחלק משלו.
- **מוצר חדש:** "+ מוצר חדש" ← שם, מחיר וכתובת באנגלית. המוצר נוצר מוסתר. ממלאים תמונות, מלאי ושדות, ואז מסמנים "מוצג באתר".
- **להוריד מוצר מהאתר:** מבטלים את "מוצג באתר". אם רק אזל זמנית: מבטלים את "זמין להזמנה" (יופיע "בקרוב").
- **עלות:** נשמרת רק בממשק הניהול ולא מוצגת באתר.

## מארזים, קטגוריות, הגדרות
- **מארזים:** מחיר, פריטים וכמויות, "עד כמה עיצובים שונים", תמונות.
- **הגדרות:** מחיר משלוח, ימי הכנה, עיר לאיסוף, מחיר אריזה, הנחת כמות.

## אבטחה במחשב
סיסמה למחשב, תיקייה אחת קבועה לקבצי הזמנות, ומחיקה מהמחשב אחרי המסירה.
